СВИНОЛЁТ — Голубиная тревога

Что внутри:
- app/src/main/assets/index.html — готовая мобильная мини-игра.
- Android-проект WebView для сборки APK.

Как играть:
- Нажми «ПОЛЕТЕЛИ».
- Кнопка ↔ двигает свинью вправо (на клавиатуре также стрелки/A/D).
- ОГОНЬ запускает мультяшные энергетические шарики.
- ↑ ускоряет подъём.
- Поймай 15 голубей, чтобы выиграть.

Как собрать APK:
1. Установи Android Studio.
2. Открой папку PigFlyGame как проект.
3. Дождись Gradle Sync.
4. Выбери Build → Build Bundle(s) / APK(s) → Build APK(s).
5. APK появится в app/build/outputs/apk/debug/.

Это исходный проект; готовый подписанный APK здесь не собран.
