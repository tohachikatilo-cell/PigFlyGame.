Как получить APK с телефона через GitHub Actions:

1. Открой github.com в браузере и войди/создай бесплатный аккаунт.
2. Создай новый репозиторий (New repository), например PigFlyGame.
3. Распакуй ZIP-архив на телефоне.
4. Загрузи содержимое папки проекта в репозиторий через Add file → Upload files. Важно сохранить структуру папок, включая app, .github и файлы Gradle.
5. Открой вкладку Actions репозитория.
6. Выбери workflow “Build PigFlyGame APK” и нажми Run workflow.
7. Дождись зелёной галочки завершения сборки.
8. Открой запуск workflow, найди Artifacts и скачай PigFlyGame-debug-apk.
9. Распакуй скачанный архив и установи app-debug.apk. Android может попросить разрешить установку из этого источника.

Это debug APK для личной установки, не публикационная подписанная версия.
